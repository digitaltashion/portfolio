About CyberShield

Project Purpose

CyberShield is a Final Year Project built to raise cyber security awareness among students and non-technical users in Pakistan. Rather than static articles, it uses interactive tools, simulations, and gamified learning to help people practice identifying threats — not just read about them.

Features

  • 6 interactive security tools
  • Real Pakistani scam case studies
  • Gamified quizzes with badges
  • Progress saved locally (privacy-first)
